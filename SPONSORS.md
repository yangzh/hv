# Sponsorship and commercial support

`hv` / [`kongming-rs-hv`](https://pypi.org/project/kongming-rs-hv/) is maintained
by [Zhonghao (Kevin) Yang](https://www.linkedin.com/in/yangzh/). All code in this
repository — Python source, examples, and documentation — is released under the
[MIT License](LICENSE) and is free to use, including commercially. The
underlying engine, shipped as a compiled extension in the published wheel, however, is proprietary.

There are two separate ways to work with the project. Pick whichever matches
what you need — they are independent.

## 1. Fund the project

Support goes toward maintenance, documentation, and keeping the Rust, Go, and
Python implementations at parity.

- **[Buy Me a Coffee](https://buymeacoffee.com/yangzh)** — one-off or monthly,
  no account needed beyond a card.
- **GitHub Sponsors** — recurring, billed through your existing GitHub account.

Companies that simply want the library maintained are welcome here; GitHub
Sponsors can bill an organization **by invoice**, which is usually easier for
procurement than a card. Sponsoring organizations can be listed below on
request.

This is support for open-source work. It carries no SLA, no guaranteed response
time, and no commitment to implement particular features.

## 2. Paid consulting and support

For work with a defined scope and a contract, this is the right channel — not a
sponsorship tier. Typical engagements:

- **Integration** — applying hypervector representations to your data, or
  embedding the library into an existing system.
- **Training and knowledge transfer** — walkthroughs of the substrate, the
  dependency parser, and how to read a decode.
- **Feature development** — prioritised work on the library itself, upstreamed
  under the project's existing licensing unless agreed otherwise.
- **Support agreement** — a defined response time for issues affecting you.

To start a conversation, use the
[contact form](https://docs.google.com/forms/d/e/1FAIpQLSeAPEzqIgcf1CYJZJepN2jtNy1QTPKtpQYkdBBs1-rNeIuoGQ/viewform)
and mention the scope and timeline you have in mind.
