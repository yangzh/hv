# Concepts

The ideas behind the library, independent of any particular language binding. Start here for the mental model; jump to the [API Reference](../api/hv/overview.md) for the concrete surface.

| Concept | Description |
|---------|-------------|
| [Hypervectors](hypervectors.md) | High-dimensional sparse binary vectors, similarity, and distance |
| [Operators](operators.md) | Bind and bundle — the algebra of composition |
| [Composites](composites.md) | Structured types built from the operators |
| [Near-neighbor search](near_neighbor_search.md) | Exact similarity retrieval over the substrate |
| [Learner](learner.md) | Online bundling over a stream, a fixed budget, the diversity margin |
| [LearnerPool](learner_pool.md) | Pooled Learners: capacity beyond a single bundle |
